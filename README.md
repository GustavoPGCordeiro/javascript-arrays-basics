# JavaScript Arrays Fundamentals

## Description

This project contains a collection of beginner-friendly JavaScript exercises focused on learning how to work with arrays.

The exercises cover essential concepts such as creating arrays, accessing elements, adding new items, and retrieving values using indexes.

## Features

### Array Creation

- Create empty arrays.
- Create arrays containing predefined values.
- Organize different types of data into lists.

### Element Access

- Access the first element of an array.
- Access the second element of an array.
- Access the last element using the array length property.

### Adding New Elements

- Use the `push()` method to insert new items into an existing array.
- Expand arrays dynamically.

## How to Run

### Option 1: Browser Console

1. Clone the repository:

```bash
git clone https://github.com/GustavoPGCordeiro/javascript-arrays-basics.git
```

2. Open the JavaScript file.

3. Copy the code into your browser's Developer Console.

4. Execute the script.

### Option 2: Using Node.js

1. Install Node.js.

2. Clone the repository:

```bash
git clone https://github.com/GustavoPGCordeiro/javascript-arrays-basics.git
```

3. Open a terminal in the project folder.

4. Run:

```bash
node app.js
```

## Core Functionalities

### Create Arrays

```javascript
let linguagensDeProgramacao = [
```

### Add Elements

```javascript
linguagensDeProgramacao.push('Java', 'Ruby', 'GoLang');
```

```javascript
console.log(listaDeNomes[listaDeNomes.length - 1]);
```
